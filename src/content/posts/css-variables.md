## Notes

JS 與 CSS 一同作出具有調整內邊距、模糊、邊框色的即時濾淨效果。

## Snippets

`filter: blur()` 為 CSS 的濾鏡功能，`blur()` 的參數越高越模糊。

用 `dataset` 可取出目標的 `data-*` 屬性，等於 `getAttribute`。

`style.setProperty()` 等同 `style.cssPropertyName` 的效果。
